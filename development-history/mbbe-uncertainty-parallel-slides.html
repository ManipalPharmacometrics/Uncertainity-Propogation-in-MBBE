Motivation & Background

What is Model-Based Bioequivalence?

Traditional BE
Conduct a clinical trial → apply NCA → compute 90% CI for GMR → check [0.80, 1.25]
Model-Based BE (MBBE)
Fit a population PK model → simulate virtual BE trials → assess BE on simulated data

Why MBBE?

  • Leverage existing PK data (e.g., from Phase I/II)
  • Explore design choices in silico
  • Predict probability of BE success
  • Reduce cost and risk of pivotal trials

The Uncertainty Problem

Problem: θ̂ are estimates with uncertainty. If we treat them as fixed truth, our BE predictions may be overconfident.

Question: How do different methods of propagating parameter uncertainty affect power and Type I error of MBBE simulations?

Study Design

PK Model

One-Compartment Oral Model

Depot' = −Ka · Depot
Central' = Ka · Depot − (CL/V) · Central
Cp = Central / V
DV ~ Normal(Cp, σ)

Bioavailability control:
Test: F = tvbio  |  Reference: F = 1.0
⇒ AUCT/AUCR = tvbio at population level

Inter-Individual Variability

CLi = tvcl · eη1
Vi  = tvv · eη2
Kai = tvka · eη3
η ~ MVN(0, Ω)
Ω = diag(0.09, 0.09, 0.09)

√0.09 = 0.30 ⇒ ~30% CV on each parameter

True (Ground Truth) Parameters

ParameterValueDescription
tvcl5.0Typical clearance (L/hr)
tvv50.0Typical volume (L)
tvka1.2Typical absorption rate (1/hr)
tvbio1.0True T/R ratio (true BE)
Ωdiag(0.09, 0.09, 0.09)IIV (~30% CV)
σ0.2Additive residual error
The reference trial is simulated with tvbio = 1.0 (true bioequivalence), then the model is re-estimated using FOCE to obtain θ̂.

Parallel-Design BE Trial

Design: Two independent groups
  • Group 1: receives Reference (R)
  • Group 2: receives Test (T)
Dose: 100 mg oral, single dose
Sampling: 0–72 hours (hourly)
Sample sizes explored: 12, 24, 30, 40, 50, 60, 80 per arm

BE Acceptance Criterion (TOST)

0.80 ≤ 90% CI of GMR ≤ 1.25

Both AUC and Cmax must pass for overall BE.


T/R Ratios Explored

0.7 0.9 1.0 1.1 1.3

0.7 & 1.3 = outside BE limits (Type I error)
0.9, 1.0, 1.1 = within BE limits (Power)

Uncertainty Propagation Methods

Four Methods Compared

1 Fixed (No Uncertainty)

Use point estimates θ̂ directly.
No variability in parameters across simulations.

Cost: None   Baseline comparator

2 VCOV (Asymptotic Normal)

Sample from multivariate normal using the variance-covariance matrix from FOCE fit.

Cost: Minimal (matrix inversion at MLE)

3 Bootstrap

Resample data → re-fit model 100 times → sample from bootstrap covariance.

Cost: High (100 re-fits)

4 SIR (Sampling Importance Resampling)

Evaluate likelihood at many candidates → resample by importance weights.

Cost: Moderate (no re-fitting)

How Parameters Are Sampled

All methods use the same sampling helper (for VCOV, Bootstrap, SIR):

1. Form μ = log(θ̂)    (log of all point estimates)

2. Draw θ* ~ exp( MVN(μ, V) )    (sample on log scale, exponentiate back)

Why log scale?
All PK parameters (CL, V, Ka, Ω, σ) are strictly positive. Sampling on the log scale and exponentiating back guarantees positivity.
Each method differs in V:
• VCOV: V = asymptotic covariance
• Bootstrap: V = bootstrap covariance
• SIR: V = SIR-derived covariance
All generate 200 parameter sets.

Key mechanism: In Fixed method, θ* = θ̂ every time. In uncertainty methods, each simulation draws a different θ*, propagating estimation uncertainty into the BE assessment.

Metrics

Power

Definition: BE pass rate when the true T/R ratio is within the BE limits.

Measured at T/R ∈ {0.9, 1.0, 1.1}

Goal: Should be high (≥ 80%)

Type I Error

Definition: BE pass rate when the true T/R ratio is outside the BE limits.

Measured at T/R ∈ {0.7, 1.3}

Goal: Should be controlled (≤ 5%)

Why Is Type I Error Inflated?

Mechanism: Uncertain parameters occasionally produce simulated trials where the apparent T/R ratio shifts toward 1.0, even though the true T/R is 0.7 or 1.3.
Counterintuitive: Type I error increases with sample size for uncertainty methods, because larger trials have more powerful TOST tests that are more likely to declare BE when parameters are favorably drawn.

This is a serious regulatory concern — uncertainty propagation as implemented here could lead to approving non-bioequivalent products.

Key Takeaways

Summary of Findings

1. Fixed method
Highest power, well-controlled Type I error (<1%). But overconfident — ignores real-world uncertainty.
2. Power penalty
Uncertainty propagation costs 5–15 percentage points of power, requiring 10–20 extra subjects per arm.
3. Inflated Type I error
All uncertainty methods show 15–21% Type I error at larger sample sizes — far above the 5% nominal level.
4. Methods are similar
VCOV, Bootstrap, and SIR yield broadly comparable results. VCOV is the cheapest computationally.

The Uncertainty Dilemma


Ignore

uncertainty
Pro: Controlled Type I error
Con: Optimistic power estimates

Propagate

uncertainty
Pro: More realistic simulations
Con: Inflated Type I error (up to 21%)


Implication: Neither approach is fully satisfactory. The field needs methods that propagate uncertainty while maintaining Type I error control — potentially through calibration, restricted sampling, or alternative uncertainty frameworks.

Regulatory Implications

Type I error inflation is the most critical finding.
If an uncertainty-propagated MBBE simulation suggests a product is bioequivalent, there is up to a ~20% chance this conclusion is wrong when the true T/R ratio is outside [0.80, 1.25].

Recommendations

  • For sponsors: Report both Fixed and uncertainty-propagated results to bracket the true operating characteristics
  • For regulators: Be cautious interpreting MBBE results with uncertainty propagation — consider requiring calibration studies
  • For methodologists: Develop approaches that decouple uncertainty propagation from Type I error inflation
  • Sample sizing: Plan for 50–60 subjects per arm in parallel designs to ensure adequate power even with uncertainty
