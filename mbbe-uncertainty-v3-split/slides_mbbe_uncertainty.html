What Changed Since v3

v3 results for VCOV, Bootstrap and SIR are withdrawn. They came from a coding error in sample_from_vcov: a natural-scale covariance matrix was used as a log-scale covariance. The ≈10–23% “type I error” and the 10–16 pp power loss reported in v3 are artefacts of that error.

Background & Design

Virtual BE framework, model and uncertainty methods

Model-Based Bioequivalence (MBBE)

  • A population PK model fitted to existing data is used to simulate virtual BE trials
  • Used to predict power, choose sample size, and map formulation changes that would still pass
  • The parameters driving the simulation are estimates, not the truth
Core question: does carrying parameter uncertainty into the virtual trials change power or false acceptance — and does the method (asymptotic, bootstrap, SIR) matter?

Plug-in vs propagated

Plug-in: power conditional on one parameter vector — “will the trial pass if our estimates are right?”

Propagated: expected power over plausible parameter values (assurance) — “how likely is it to pass, given what we know?”

Controlled simulation with a known truth, so every operating characteristic can be checked.

Virtual BE Trial Design

Parallel-Group Design

  • Two independent arms: Test and Reference
  • Single 100 mg oral dose; hourly sampling 0–72 h
  • NCA endpoints: Cmax and AUC0–t (to last observation at 72 h, linear-up/log-down)
  • Between-subject %CV under plug-in estimates: AUC0–t 22.5%, Cmax 20.9%
True T/R set by the test-product bioavailability F (tvbio); the model is linear, so F is the true T/R for both AUC and Cmax.

Population PK Model

Structural Model

Depot' = −Ka · Depot
Central' = Ka · Depot − (CL/V) · Central

Cp = Central / V

Inter-Individual Variability

CLi = tvCL · eη1,   Vi = tvV · eη2,   Kai = tvKa · eη3

η ~ N(0, Ω),   Ω = diag(0.09, 0.09, 0.09)

The Four Methods

1. Fixed (Plug-in)

The FOCE point estimate θ̂ is used for every virtual trial. No uncertainty propagated. Reference baseline.

1 vector: θ̂

2. VCOV (Asymptotic)

Draws from a multivariate normal on the log scale, with the natural-scale covariance of the estimates transformed by the delta method.

1,000 delta-method draws

3. Bootstrap

Subjects resampled with replacement, model refitted to each replicate. The refitted parameter vectors are used directly. All 500 refits converged.

500 empirical refit vectors

4. SIR

Proposals drawn from the asymptotic distribution, weighted by importance ratios and resampled (Dosne et al.). Resampled vectors used directly.

2,000 proposals → 1,000 resamples

How Uncertainty Is Propagated

VCOV draws: delta-method transform

θ̂ = [tvCL, tvV, tvKa, tvbio, ω²1, ω²2, ω²3, σ]

Σ̂ = vcov(fit)  (natural scale)
D = diag(θ̂)
Cov(log θ) ≈ D−1 Σ̂ D−1

log θdraw ~ MVN(log θ̂, D−1 Σ̂ D−1)
θdraw = exp(log θdraw)  (always positive)
Bootstrap and SIR need no transform: their empirical vectors are used as drawn.

Per-Trial Simulation Flow

Step 1 Draw one vector at random from the method's set
Step 2 Overwrite tvbio with the nominal T/R
Step 3 Simulate n Test + n Reference subjects
Step 4 NCA → AUC0–t, Cmax
Step 5 TOST on log-scale values
Result Pass = AUC0–t and Cmax 90% CI within 80–125%

Uncertainty acts only on CL, V, Ka, Ω and σ (nuisance parameters). Uncertainty in F is deliberately not propagated — it would change the truth being tested.

TOST for Parallel-Design BE

Two One-Sided Tests

H0: μT − μR ≤ log(0.80) or ≥ log(1.25)
H1: log(0.80) < μT − μR < log(1.25)

GMR = exp(Δ),   Δ = x̄T − x̄R
90% CI = exp(Δ ± t0.95, df · SE)
BE concluded: 90% CI of the GMR within [0.80, 1.25] for both AUC0–t and Cmax

Parallel Design Specifics

  • Pooled-variance two-sample t-test on log values
  • SE = √(sp² · (1/nR + 1/nT))
  • df = 2n − 2

Operating Characteristics

  • Power: P(conclude BE) at T/R 0.90, 1.00, 1.10
  • False acceptance: P(conclude BE) at T/R 0.70, 1.30 (outside the limits)
  • Mean over 20 batches; 95% CI from the batch SE
  • n for 80% power at T/R 1.00: linear interpolation between adjacent n

Why: the terminal phase falls below the residual SD (0.2 mg/L) within 72 h, so the extrapolation slope is fitted largely to noise. This inflates the variability of AUC0–∞ and compresses its ratio towards 1 (median AUC0–∞ ratio 0.80–0.82 at a true 0.70, even for plausible V).

What Went Wrong in v3

The covariance scale error, its mechanism and the diagnostic re-run

The Bug: Natural-Scale Covariance Used as Log-Scale

v3 sample_from_vcov (schematic)

V = vcov(fit)  # natural scale (Pumas)
dist = MvNormal(log.(θ̂), V)  # treated as log scale
θ = exp.(rand(dist))

v4 (corrected)

D⁻¹ = Diagonal(1 ./ θ̂)
dist = MvNormal(log.(θ̂), D⁻¹ V D⁻¹)  # delta method
θ = exp.(rand(dist))

Bootstrap and SIR arms in v3 were also drawn through this function (from the covariance of the bootstrap / SIR results), so all three propagation arms were affected — which is why they looked alike.

What it did to V

  • SE(θV) = 2.12 L on an estimate of 51.4 L (RSE 4.1%)
  • Correct log-scale SD ≈ 2.12 / 51.4 ≈ 0.04
  • Used as-is on the log scale: log-SD = 2.1
  • Drawn V spanned 0.96–2,120 L (95% range) instead of 47.5–55.0 L
Parameters with small natural-scale variances (Ω, σ) went the other way: drawn with almost no uncertainty.

Key Findings & Conclusions

Key Findings

1. Method choice has little effect with an informative reference study

Power differs from Fixed by at most 3.4 pp, only at 12–40 subjects per arm (≤ 1.2 pp from n = 50); n for 80% power 21.5–22.2 per arm for all four methods.

2. Correct propagation does not inflate false acceptance

≤ 0.2% at T/R 0.70 and 1.0–2.2% at 1.30, flat in n. Propagation acts only on nuisance parameters; TOST controls its size at each of their values.

3. Implementation and endpoint choices dominate

A wrongly scaled covariance produced up to ~25% false acceptance; AUC0–∞ under a noise-dominated terminal phase raised n for 80% power from ~22 to ~33 per arm.

4. A rising false-acceptance rate is a diagnostic of failure

At ratios outside the limits, a pass rate that rises with n signals broken propagation or a model producing data in which T/R can no longer be measured.

Conclusions

  1. Propagation changes the question from “will the trial pass if our estimates are right?” to “how likely is it to pass, given what we know?”
  2. With an informative reference study, asymptotic, bootstrap and SIR give very similar answers to each other and to the plug-in approach, and none inflates false acceptance at non-equivalent ratios.
  3. Implementation choices matter far more. A covariance sampled on the wrong scale gave up to ~25% false acceptance; an AUC endpoint dominated by residual error inflated the planned sample size by about half (33 vs 22 per arm).
  4. The pass rate at ratios outside the limits, and its trend with n, is a simple and effective check on any uncertainty-propagation pipeline.

Recommendations

Implementing propagation

  • Reconcile scales: delta-method transform of the natural-scale covariance, or parameterise on the log scale throughout
  • Use bootstrap / SIR parameter vectors directly, not an MVN built from their covariance
  • Compare sampled distributions with the estimates and SEs before running any trials
  • Methods that should differ but look identical are a warning sign

Reporting & design

  • Report the pass rate at ratios outside the limits alongside power, across n
  • Treat the endpoint definition as a modelling decision; where extrapolated AUC is needed, check the residual-error model and sampling window against a realistic LLOQ
  • Expect method differences when the reference study is small or sparse, variance components are poorly estimated, or the model is strongly nonlinear

Limitations & Technical Details

Limitations

  • Simple model: one compartment, linear, single dose, additive error
  • Informative reference study (60 subjects × 73 samples) favours the asymptotic approximation
  • Parallel design only; crossover / replicate designs may behave differently
  • Parameter uncertainty only, not model-structure uncertainty
  • 2,000 trials/cell: differences below ~2 pp cannot be resolved
  • Additive error compresses ratios; low false acceptance at 1.30 depends on Cmax being co-primary. A proportional/combined error model would be more realistic
  • Natural extensions: less informative reference study, NTI limits
